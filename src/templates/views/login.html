⭐ HH Job Analyzer: Проект для Портфолио

**HH Job Analyzer** — это полноценное решение для сбора, хранения и глубокого анализа данных о вакансиях с HeadHunter. Проект демонстрирует навыки работы с многокомпонентной архитектурой, асинхронными задачами и аналитикой больших данных.

Ключевой стек и особенности:

  • **Backend:** Python/Flask (MVC-подобная структура).
  • **База данных:** PostgreSQL с ORM (Peewee/SQLAlchemy).
  • **Архитектура:** Docker Compose (Flask, DB, Worker, Redis) для быстрого развертывания.
  • **Автоматизация:** **APScheduler** для регулярного сбора данных и **RQ/Redis** для обработки фоновых задач.
  • **Аналитика:** Визуализация популярных навыков, сравнение навыков со средней зарплатой.
  • **Оптимизация:** Кэширование запросов и графиков в Redis для высокой производительности.
