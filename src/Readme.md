# 📈 HH Job Analyzer: Парсер и Анализатор Вакансий (HeadHunter)

## 🌟 Описание проекта

**HH Job Analyzer** — это полноценный веб-приложение для **сбора, фильтрации и аналитической визуализации** данных о вакансиях с сайта HeadHunter (HH). Проект разработан на базе **Python/Flask** и использует микросервисный подход для масштабируемости и надежности.

## 🚀 Основная функциональность

### 1. Вакансии
* **Продвинутый поиск:** Фильтрация вакансий по ключевым словам (в названии или навыках), диапазону зарплат, городу, компании и типу занятости (удаленная работа).
* **Кэширование:** Быстрый повторный доступ к результатам поиска благодаря кэшированию в Redis.

### 2. Аналитика
* **Популярность навыков:** Построение диаграмм востребованных навыков для конкретной профессии.
* **Сравнение Зарплат и Навыков:** Визуализация связи между требуемыми навыками и средней заработной платой.
* **Анализ по компаниям:** Отображение уровня зарплат по различным профессиям внутри указанной компании.

### 3. Администрирование
* **Ручной сбор:** Единовременный запуск парсинга для новой профессии.
* **Автоматизация:** Настройка **регулярного** сбора данных по списку профессий с использованием планировщика (APScheduler).
* **Обслуживание:** Автоматическое удаление сгенерированных графиков и кэша по таймеру.

## 🛠️ Стек Технологий

| Категория | Технологии |
| :--- | :--- |
| **Backend** | Python, Flask |
| **База данных** | PostgreSQL |
| **ORM** | Peewee  |
| **Кэширование / Очереди** | Redis, RQ Worker |
| **Планировщик задач** | APScheduler |
| **Оркестрация** | Docker, Docker Compose |

## 🧱 Архитектура Docker Compose

Проект состоит из четырех основных сервисов:

| Сервис | Описание |
| :--- | :--- |
| **flask** | Основное веб-приложение (Backend) на Flask. Зависит от готовности DB и Redis. |
| **db** | Контейнер с PostgreSQL. Использует `healthcheck` для проверки готовности к приему соединений. |
| **redis** | Контейнер с Redis. Используется для кэширования и в качестве брокера для RQ. |
| **worker** | Отдельный процесс для обработки фоновых задач (RQ), таких как длительный парсинг или анализ. |
